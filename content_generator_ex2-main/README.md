# AI-Powered Blog Content Generator using Ollama

## 24CS2506 – Building Applications using GPT-4

An AI-powered Blog Content Generator developed using Python and Ollama with the Llama 3.2 language model.

## Features

- AI-powered blog generation
- Multiple writing styles
- Different tones
- Custom word count
- Blog title generation
- SEO keyword generation
- Blog summary generation
- SEO meta description generation
- LLM-based intent detection
- Continuous menu-driven interaction
- Save generated blog to a text file

## Technologies Used

- Python
- Ollama
- Llama 3.2
- Requests
- VS Code
